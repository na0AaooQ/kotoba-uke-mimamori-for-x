How to Use Kotoba Uke Mimamori

When Kotoba Uke Mimamori is enabled, it can add a gentle cushion before reading wording on X that may feel emotionally heavy. You can choose whether to read the content or not read it now.

1. Getting started

  1. Load Kotoba Uke Mimamori as a Google Chrome extension.
  2. Open the extension options page.

The extension is OFF by default. You can turn it ON when you want to start using it.

2. Turn the extension ON

  1. In the options page, turn on "Enable Kotoba Uke Mimamori".
  2. Reload the open X page.

At this stage, ON/OFF changes take effect after reloading the open X page.

3. Choose cushion sensitivity

In the options page, you can choose how easily cushions are shown. The default setting is Standard.

  • Less: Shows cushions mainly for stronger expressions.
  • Standard: Uses the standard setting.
  • More: Shows cushions more readily for lighter-risk wording.

After changing this setting, reload the open X page to apply it. Changing the sensitivity does not delete posts or rate posters.

4. When a cushion is shown

When the extension is ON, a cushion UI may be shown for a post that contains wording that could feel emotionally heavy.

  • "Show content" removes the blur from the post text and closes the UI.
  • "Not now" keeps the blur and folds the cushion UI.

The folded UI still keeps "Show content", so you can choose to read the content later if you want to.

The blur is applied to the post text. The extension does not erase the post completely, and it does not remove the post DOM.

5. Turn the extension OFF

  1. Open the options page.
  2. Turn off "Enable Kotoba Uke Mimamori".
  3. Reload the open X page.

6. If it does not seem to work

  • After changing ON/OFF or cushion sensitivity, reload the open X page.
  • If you want to stop cushions, turn the extension OFF in the options page and reload X.

The current MVP applies setting changes when the X page loads, so a page reload is needed after changing settings.

7. What this tool values

Kotoba Uke Mimamori adds a cushion before reading instead of erasing posts completely. It leaves both the freedom to read and the freedom not to read now with the user.

Post text and detection results are not sent externally. Detection runs locally in the browser, and the only saved settings are enabled and cushionSensitivity.

This extension does not replace X's built-in mute features. It is a supplemental tool that adds a gentle pause before reading.
