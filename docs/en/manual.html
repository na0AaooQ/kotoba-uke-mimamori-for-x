How to Use Kotoba Uke Mimamori

When Kotoba Uke Mimamori is enabled, it can add a gentle cushion before reading wording on X that may feel emotionally heavy. You can choose whether to read the content or not read it now.

1. Add the extension from the Chrome Web Store

Add the published beta version from the Chrome Web Store, enable it from the popup, and confirm that a cushion can appear on X. The screenshots below show the Japanese Chrome interface.

  1. Open the Kotoba Uke Mimamori Chrome Web Store page.
  2. Click "Add to Chrome".
  3. If a warning screen appears, review the message and click "Continue to install".
  4. On the permission confirmation screen, click "Add extension".
  5. Confirm that Kotoba Uke Mimamori has been added to Chrome.
  6. Open the extension menu in the upper-right corner of Chrome and pin Kotoba Uke Mimamori to the toolbar.
  7. Click the Kotoba Uke Mimamori toolbar icon to open the popup.
  8. Turn the extension ON when needed, then choose Less, Standard, or More for cushion sensitivity.
  9. Open X and confirm that a cushion is shown on a matching post.
  10. Click "Not now" to keep the post blurred while leaving the option to show it later.
  11. Click "Show content" to remove the blur and view the post text.

2. Change ON/OFF and sensitivity in the popup

The popup can turn the extension ON/OFF. The initial state is OFF, and you can turn it ON when you want to use it.

  • Cushion display sensitivity can be selected from Less, Standard, or More.
  • Post text and detection results are not sent to external servers.
  • ON/OFF and sensitivity changes take effect after reloading the open X page.

3. When a cushion is shown

When the extension is ON, a gentle cushion may be shown before reading a post that includes wording that could feel emotionally heavy.

  • The post text is blurred.
  • "Show content" displays the post text.
  • "Not now" keeps the post blurred and lets you show it later.
  • The extension does not delete the post text or post DOM.

4. After choosing Not now

If you choose "Not now", the post stays blurred for now. You can still choose "Show content" later if you want to read it.

5. After choosing Show content

Choosing "Show content" removes the blur and shows the post text normally.

6. If it does not seem to work

  • After changing ON/OFF or cushion sensitivity, reload the open X page.
  • If you want to stop cushions, turn the extension OFF in the popup or options page and reload X.
  • If X was already open when the extension was added or updated, reload the X page.

The current MVP applies setting changes when the X page loads, so a page reload is needed after changing settings.

7. What this tool values

Kotoba Uke Mimamori adds a cushion before reading instead of erasing posts completely. It leaves both the freedom to read and the freedom not to read now with the user.

Post text and detection results are not sent externally. Detection runs locally in the browser, and the only saved settings are enabled and cushionSensitivity.

This extension does not replace X's built-in mute features. It is a supplemental tool that adds a gentle pause before reading.
