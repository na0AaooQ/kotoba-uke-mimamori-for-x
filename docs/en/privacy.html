1. Information not sent externally

This extension checks post text shown on X inside your browser. Post text and detection results are not sent to external servers.

The extension does not add a system that collects the checked text or internal checking details outside your browser.

It helps users choose whether to read the content or not read it now.

  • Post text is not sent to external servers.
  • Detection results are not sent to external servers.
  • Post text is not saved.
  • Detection results are not saved.
  • Browsing history is not saved.
  • Post URLs are not saved.
  • Usernames and account IDs are not saved.
  • Internal detection details are not saved.

2. Saved settings

The only saved settings are the extension ON/OFF setting and the cushion display sensitivity setting.

The only settings saved in chrome.storage.local are enabled, which represents whether the extension is ON, and cushionSensitivity, which represents how easily cushions are shown.

On the public documentation pages, only the display theme preference is saved in the browser's localStorage so your selection can be retained. The saved value is limited to system, light, or dark.

The theme preference does not store post text, detection results, browsing history, pages or URLs viewed, usernames, account IDs, or other user information. It is not sent externally, and these pages do not use cookies or analytics. If site data is cleared, this preference is also removed and the pages return to the System setting.

Post text is not saved. Detection results are not saved. Browsing history is not saved. Post URLs are not saved. Usernames and account IDs are not saved.

Internal checking details such as score, matchedRules, categories, and reasons are not saved.

3. What the extension does not do

  • It does not rate accounts.
  • It does not automatically block posts or accounts.
  • It does not automatically report posts or accounts.
  • It does not remove post text or post DOM.
  • It does not evaluate posters.
  • It does not send post content to an external system for monitoring or evaluation.
  • It does not add external communication from Kotoba Uke Mimamori.

This extension is not for judging posters. Its role is limited to adding a gentle cushion before reading, so the user can choose whether to read now or not.

4. External communication

No external communication has been added by Kotoba Uke Mimamori in the current MVP.

Post text and detection results are not sent to external servers.
